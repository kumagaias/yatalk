# Yatalk custom domain

- Goal: use `yatalk.kumagaias.com` for the Yatalk dev-preview site and API.
- Decision: use one HTTPS origin for the site and `/api/*`, backed by direct Cloud Run domain mapping for the dev preview. A separate `api.` hostname and a load balancer are unnecessary for this path. Cloud Run custom domain mapping is Preview and Google documents latency limitations for `asia-northeast1`; keep this approach scoped to dev preview and reassess before production.
- DNS: central Route 53 Terraform root `infra/yatalk-domain` owns the fixed `yatalk.kumagaias.com` RRsets with TTL 300 and overwrite disabled. It accepts the `{type, rrdata}` list from the Yatalk output `custom_domain_dns_records`, groups A, AAAA, or CNAME values by type, and rejects CNAME mixed with A/AAAA. The default matches the applied mapping record `CNAME ghs.googlehosted.com.`.
- Status: the Cloud Run domain mapping and Route 53 CNAME are applied, and the Google-managed TLS certificate is active. `APP_ORIGIN` now uses `https://yatalk.kumagaias.com`; the PayPal Sandbox webhook uses `/api/webhooks/paypal` with its existing ID and capture/refund subscriptions. The default `run.app` URL is disabled; Cloud Run ingress and public invoker remain configured for the mapped service.
- Checks: Terraform formatting and validation passed. Read-only plans showed one domain-mapping create, one `APP_ORIGIN` service update, and one default-URL service update; the final plan reported no changes after refreshing the default URI output. Headless homepage and API health returned 200; allowed-origin handling proceeded to the expected 401 for a missing visitor session, while an attacker origin returned 403. The disabled `run.app` URL returned 404. PayPal Sandbox simulation returned 202 and the custom webhook route returned 204 after default-URL disablement. Central DNS default-plan reported no changes; the Route 53 CNAME resolved publicly.
- Next: before production, reassess Cloud Run's Preview domain-mapping limitations and latency; complete a buyer-approved checkout/capture/refund rehearsal when the Sandbox buyer is available.
